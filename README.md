# DecodeLabs-Project-1
# Data Cleaning & Preparation

# Objective

The objective of this project was to clean and prepare raw data for analysis.

# Tasks Performed

- Identified missing values
- Removed duplicate records
- Verified duplicate Order IDs
- Checked date formatting consistency
- Filled missing CouponCode values with "No Coupon"

# Tools Used

- Python
- Pandas
- Google Colab
- Excel Dataset


# Outcome

Successfully transformed raw data into a clean and analysis-ready dataset.
